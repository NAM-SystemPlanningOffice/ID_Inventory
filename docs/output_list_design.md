# リスト出力設計

## 3つのリストの違い

| 項目 | ユーザー棚卸リスト | 退職者ID削除依頼書 | 組織転出者アクセス権限確認リスト |
|------|-------------------|-------------------|---------------------------|
| **実行タイミング** | 月次（任意） | 異動日指定 | 異動日指定 |
| **事前確認** | 取り込み状況確認 | 取り込み状況確認 | 取り込み状況確認 |
| **対象ユーザー** | システム全ユーザー | 指定日の退職者のみ | 指定日の転出者のみ |
| **在籍判定時点** | 現時点 | 指定日時点 | 指定日時点 |
| **出力条件** | システムごとに設定可能 | 固定（退職者のみ） | 固定（転出者のみ） |
| **出力フォーマット** | システムごとにシート分割（縦） | 1シート・横持ち表形式 | システムごとにシート分割（縦） |
| **システム固有項目** | `output_columns_json` | `taishoku_display_sql` | `output_columns_json` |
| **在籍ユーザー属性** | 本務所属・兼務所属・役職 | なし | 転出元組織・転出先組織 |

## 1. ユーザー棚卸リスト

### 目的
各システムのユーザーIDが適切に管理されているか、月次で確認する。

### 実行フロー

```
[月次実行]
    ↓
[取り込み状況確認画面表示]
  - システムごとの最終取り込み日時
  - 取り込み未実施のシステムを強調表示
    ↓
[ユーザーが確認・取り込み実施]
    ↓
[棚卸リスト出力実行]
    ↓
[Google Sheets出力（システムごとにシート分割）]
```

### 出力モード

| モード | 説明 | 用途 |
|-------|------|------|
| `ALL` | 全ユーザー出力 | 小規模システム |
| `MISMATCH_ONLY` | 在籍マッチング不可のみ | 標準（最多） |
| `CUSTOM` | カスタムフィルタSQL適用 | 特殊要件 |

**カスタムフィルタ例**:
- `ACCOUNT_STATUS != 'Disabled'` （Disableユーザー除外）
- `PERMISSION_LEVEL NOT IN ('User', 'Guest')` （一般権限除外）

### 画面イメージ

```
【ユーザー棚卸リスト出力】

■ 各システムの取り込み状況
┌──────────────────┬─────────────────┬────────┐
│ システム名        │ 最終取り込み日時  │ 状態    │
├──────────────────┼─────────────────┼────────┤
│ SAP人事システム   │ 2026-06-24 10:30│ OK     │
│ 営業支援システム   │ 2026-06-20 15:00│ 古い⚠  │
│ 経費精算システム   │ 未取り込み        │ 未実施❌│
└──────────────────┴─────────────────┴────────┘

[棚卸リスト出力実行] ボタン
```

## 2. 退職者ID削除依頼書・組織転出者アクセス権限確認リスト

### 出力方式
**異動日を指定して2つのリストを同時に出力**

- 退職者ID削除依頼書
- 組織転出者アクセス権限確認リスト

### 2-1. 退職者ID削除依頼書

#### 目的
指定日に退職したユーザーのアカウント削除を依頼する。

#### 出力フォーマット
**横持ち表形式**: 1行に1ユーザー、横にシステムを並べる

```
退職者ID削除依頼書
対象日: 2026-06-30

┌────────┬──────┬──────┬─────────┬─────────┬─────────┐
│ユーザーID│氏名   │所属   │システムA │システムB │システムC │
├────────┼──────┼──────┼─────────┼─────────┼─────────┤
│U00123  │山田太郎│営業部 │enabled  │12345    │－       │
├────────┼──────┼──────┼─────────┼─────────┼─────────┤
│U00456  │佐藤花子│総務部 │suspended│－       │enabled  │
│        │      │      │         │         │(2026/12)│
└────────┴──────┴──────┴─────────┴─────────┴─────────┘
```

### 実行フロー（退職者・組織転出者リスト同時出力）

```
[異動日選択]
    ↓
[取り込み状況確認画面表示]
  - システムごとの最終取り込み日時
    ↓
[該当日の退職者・転出者データ取得]
    ↓
┌─────────────────────────┬────────────────────────────┐
│ 退職者ID削除依頼書        │ 組織転出者リスト             │
│                         │                            │
│ [全システムを横持ちJOIN] │ [システムごとにデータ取得]   │
│ [表示SQLを適用]          │ [組織コード変更を除外]       │
│ [1シート・横持ち]        │ [複数組織をLISTAGG]         │
│                         │ [システムごとにシート]       │
└─────────────────────────┴────────────────────────────┘
    ↓
[Google Sheets出力（2種類のリストを含む1つのスプレッドシート）]
```

**詳細**: [taishoku_list_sql_design.md](taishoku_list_sql_design.md) 参照

### 2-2. 組織転出者アクセス権限確認リスト

#### 目的
指定日に組織を転出したユーザーの権限を確認する（組織コード変更のみは除外）。

#### 出力フォーマット
**システムごとにシート分割**: 複数組織はLISTAGGで改行区切り

```
┌────────┬──────┬────────────┬────────────┬─────────┐
│ユーザーID│氏名   │転出元      │転出先      │システムA │
├────────┼──────┼────────────┼────────────┼─────────┤
│U00123  │山田太郎│営業部(本務)│総務部(本務)│enabled  │
│        │      │課長        │部長        │         │
│        │      │開発部(兼務)│企画部(兼務)│         │
│        │      │担当        │課長        │         │
└────────┴──────┴────────────┴────────────┴─────────┘
```

**詳細**: [tenshutu_list_sql_design.md](tenshutu_list_sql_design.md) 参照

```
[退職者・組織転出者リスト出力実行] ボタン
```

## Google Sheets出力共通仕様

### スプレッドシート構成

| 出力単位 | 内容 | シート構成 |
|---------|------|-----------|
| **ユーザー棚卸リスト** | 月次、単独実行 | システムごとにシート分割 |
| **退職者・組織転出者** | 異動日指定、同時出力 | 退職者1シート + 組織転出者N シート |

### 退職者・組織転出者の詳細シート構成

**スプレッドシート名**: `退職者・組織転出者リスト_20260630`

```
シート1: 退職者ID削除依頼書（横持ち表）
シート2: 組織転出者_システムA
シート3: 組織転出者_システムB
シート4: 組織転出者_システムC
...
```

### 出力履歴管理

```sql
-- IDINV_OUTPUT_HISTORY
INSERT INTO NAM_IAM_ADMIN.IDINV_OUTPUT_HISTORY (
    output_type,
    output_datetime,
```

## エラーハンドリング

### 取り込み未実施のシステム
```python
if not system_info.last_import_datetime:
    warnings.append(f"{system_info.system_name}: データ未取り込み")
```

### 出力対象ユーザーが0件
```python
if len(system_data) == 0:
    # シートは作成するが「対象ユーザーなし」と表示
    sheet.append_row(["対象ユーザーなし"])
```

### Google Sheets API エラー
```python
try:
    spreadsheet = gsheet_client.create_spreadsheet(title)
except GoogleAPIError as e:
    record_output_history(list_type, target_date, None, 'ERROR', str(e))
    raise
```
