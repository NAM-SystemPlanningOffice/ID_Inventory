# 区切り文字とクォート文字の使用例

## 例1: 標準的なCSV（カンマ区切り）

**ファイル形式**:
```
ユーザーID,氏名,所属コード,所属名
12345,山田太郎,D001,総務部
67890,佐藤花子,D002,営業部
```

**設定**:
- 区切り文字: カンマ (,)
- クォート文字: ダブルクォート (")
- ヘッダー行あり: ✓

## 例2: タブ区切りファイル（TSV）

**ファイル形式**:
```
ユーザーID	氏名	所属コード	所属名
12345	山田太郎	D001	総務部
67890	佐藤花子	D002	営業部
```

**設定**:
- 区切り文字: タブ (\t)
- クォート文字: なし
- ヘッダー行あり: ✓

**用途**: Excelからエクスポートされたタブ区切りファイル

## 例3: セミコロン区切り＋ダブルクォート

**ファイル形式**:
```
"ユーザーID";"氏名";"備考"
"12345";"山田太郎";"部長, 総務部"
"67890";"佐藤花子";"課長, 営業部"
```

**設定**:
- 区切り文字: セミコロン (;)
- クォート文字: ダブルクォート (")
- ヘッダー行あり: ✓

**ポイント**: 備考にカンマが含まれていても、クォートで囲まれているため正しく解析されます。

**用途**: ヨーロッパ圏のExcelでエクスポートされたCSV

## 例4: パイプ区切り

**ファイル形式**:
```
ユーザーID|氏名|所属コード|所属名
12345|山田太郎|D001|総務部
67890|佐藤花子|D002|営業部
```

**設定**:
- 区切り文字: パイプ (|)
- クォート文字: なし
- ヘッダー行あり: ✓

**用途**: データベースからのエクスポート、ログファイル

## 例5: カスタム区切り文字（ダブルコロン）

**ファイル形式**:
```
ユーザーID::氏名::所属コード::所属名
12345::山田太郎::D001::総務部
67890::佐藤花子::D002::営業部
```

**設定**:
- 区切り文字: カスタム → `::` を入力
- クォート文字: なし
- ヘッダー行あり: ✓

**用途**: 特殊なシステムからのエクスポート

## 例6: シングルクォート使用

**ファイル形式**:
```
'ユーザーID','氏名','備考'
'12345','山田太郎','部長, 総務部'
'67890','佐藤花子','課長, 営業部'
```

**設定**:
- 区切り文字: カンマ (,)
- クォート文字: シングルクォート (')
- ヘッダー行あり: ✓

## クォート文字の役割

### クォートが必要なケース

1. **値に区切り文字が含まれる場合**
   ```
   "山田太郎","課長, 総務部"
   ```
   備考に`,`が含まれているため、クォートが必要

2. **値に改行が含まれる場合**
   ```
   "山田太郎","住所:
   東京都千代田区"
   ```

3. **値に空白が含まれる場合**
   ```
   " 山田太郎 ","総務部"
   ```

### クォートが不要なケース

1. **値がシンプルな文字列のみ**
   ```
   12345,山田太郎,D001,総務部
   ```

2. **タブ区切りで値に特殊文字がない**
   ```
   12345	山田太郎	D001	総務部
   ```

## トラブルシューティング

### エラー: データが正しく分割されない

**原因**: 区切り文字の設定が間違っている
**解決策**:
1. ファイルをテキストエディタで開く
2. 実際の区切り文字を確認（カンマ、タブ、セミコロンなど）
3. 正しい区切り文字を設定

### エラー: 値が途中で切れる

**原因**: クォート文字の設定が間違っている、または値にクォート文字が含まれている
**解決策**:
1. ファイル内の値がどのように囲まれているか確認
2. ダブルクォート、シングルクォート、なし を適切に選択
3. 値自体にクォート文字が含まれる場合は、エスケープされている必要がある（例: `"値""の中"` → `値"の中`）

### エラー: 列数が合わない

**原因**: 
- 区切り文字が正しく設定されていない
- クォートされた値の中に区切り文字がある

**解決策**:
1. 区切り文字とクォート文字の組み合わせを確認
2. ファイルの形式を統一（全ての値をクォートで囲むなど）
